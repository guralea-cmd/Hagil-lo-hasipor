## הארכיטקטורה (נבנתה 5.10, שלד - לא באוויר)
- **דף:** `maslul.html` + `js/maslul.js` (שם הקובץ זמני). שיחה: הודעת AI -> כפתורים (2-4) או שדה טקסט -> הודעה הבאה. בסוף: טופס שם + טלפון -> `window.sendLeadToSheet` (js/leads-sheet.js, form "ai-funnel") -> גיליון הלידים + מייל ללאה. התמלול והסיכום של ה-AI נשלחים בשדה reps (עד שתהיה לשונית משלו). **כל הטקסטים בדף מסומנים [טקסט זמני] - רק המילים של לאה נכנסות.**
- **צד שרת:** `backend/Code.gs` - Google Apps Script web app (כמו גיליון הלידים: רץ בתור guralea@gmail.com, גישה: כולם). קורא ל-Claude `claude-opus-5` ב-raw HTTP (אין SDK ל-Apps Script), תשובה ב-JSON קבוע (output_config.format json_schema): reply / options / stage / done / summary. effort low (שיחה). המפתח ב-Script Properties `ANTHROPIC_API_KEY`, הפרומפט ב-`SYSTEM_PROMPT` (מתעדכן בלי פריסה מחדש).
- **מצב הדגמה:** כש-`BACKEND_URL` ב-maslul.js ריק - הדף מריץ 4 שאלות דוגמה קבועות, כדי לראות את המסך בלי מפתח.
- **הפרומפט:** `system-prompt.md` - רק המבנה הטכני; חלק "השאלות" = מקום שמור למילים של לאה.
- **למה Apps Script ולא Firebase Functions:** Firebase Functions דורש תוכנית בתשלום (כלל 16: לא מעלים חיוב Firebase מול לאה). Apps Script כבר פרוס, כבר שלה, חינם.

## מה חסר כדי שזה יעבוד באמת (לפי סדר)
1. **מפתח API של Anthropic** - חשבון ב-console.anthropic.com + כרטיס אשראי (תשלום לפי שימוש; שיחה של 10 תורים ~ כמה אגורות עד שקל). **לאה פותחת בעצמה** (חשבון + אמצעי תשלום = רק היא); Claude מכוון שלב-שלב. אחרי זה: המפתח נכנס ל-Script Properties דרך Edge (התוסף), לא נשמר בריפו.
2. **השאלות של לאה** -> system-prompt.md -> SYSTEM_PROMPT.
3. פריסת Code.gs כ-web app (Edge, עורך Apps Script - עבד כבר ב-14.9 לגיליון) -> הכתובת ל-`BACKEND_URL`.
4. לשון הפנייה בדף: נקבה יחיד או שני המינים - **לשאול את לאה** (כלל 17.9: נקבה יחיד רק בבת-כמה; המשפך פונה "לאותה אישה" - כנראה נקבה, לא מניחים).
5. שם הדף/הכתובת, הכותרת, שורת ההסבר, טקסט הכפתור בטופס - מילים של לאה.
6. בדיקה מלאה: שיחה -> ליד -> גיליון -> מייל, ומחיקת ליד הבדיקה.
7. חיבור למשפך: קישור בפרופילים / today.html / פוסטים - לפי החלטת לאה.
