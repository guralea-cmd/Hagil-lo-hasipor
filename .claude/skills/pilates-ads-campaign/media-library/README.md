# media-library

The full method (number map, topic index, selection-page format, TikTok format, week 2 picks) is the `leah-photo-library` skill: `.claude/skills/leah-photo-library/SKILL.md`.

Files in this folder, used by that skill:
- `facebook-page-photos-map.csv` - number,file name for every photo in `מסמכים\מאגר-מדיה-לאה\facebook-page-photos`
- `build-sheets.ps1` - rebuilds the numbered contact sheets and the map
- `make-tiktok.ps1` - builds the approved 1080x1920 TikTok version of post images
