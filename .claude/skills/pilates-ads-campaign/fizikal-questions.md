# שאלות לפיזיקל (Fizikal) - לשיחה של לאה ב-14.9.2026

המטרה: כל ליד נכנס לפיזיקל לבד - בלי לרשום בדפים.
מקורות הלידים: מודעות בפייסבוק ובאינסטגרם (טופס של מטא), הטופס ב-guralea.com/pilates.html, והטופס באתר החדש guraleapilates.com. בכל הטפסים: שם וטלפון בלבד.

1. יש לכם חיבור ישיר ללידים ממודעות פייסבוק ואינסטגרם? הליד נכנס לפיזיקל ברגע שמישהי משאירה פרטים?
2. איך מחברים טופס מהאתר שלי לפיזיקל? (כתובת חיבור API / Webhook / מייל שהלידים נשלחים אליו)
3. אפשר לראות מאיפה הגיע כל ליד - פייסבוק, אינסטגרם או האתר?
4. אני מקבלת התראה כשנכנס ליד חדש? איך - הודעה, וואטסאפ, אפליקציה, מייל?
5. אפשר לסמן לכל ליד מה קרה - חדש, התקשרתי, נקבע אימון היכרות, לא רלוונטי - ולקבל תזכורת לחזור אליו?
6. מה קורה כשאותה אישה משאירה פרטים פעמיים?
7. יש אפליקציה בטלפון לראות את הלידים?
8. אפשר לשלוח לליד הודעת וואטסאפ אוטומטית כשהוא נכנס?
9. מי עושה את החיבור - אתם או אני? אילו הרשאות צריך לתת לכם (עמוד הפייסבוק, מנהל העסקים)?
10. כמה זה עולה? זה כלול בחבילה שלי?
11. אפשר להכניס לפיזיקל את הלידים שכבר יש?
12. (לאה עבדה בעבר עם חברת פרסום שהלידים שלה נכנסו לפיזיקל.) החיבור הקיים הוא לכל עמוד הפייסבוק "לאה גורא פילאטיס מכשירים ברמלה", או רק לטופס מסוים? ב-13.9 נוצר טופס חדש, "טופס לידים - שם וטלפון בלבד" - אם החיבור לפי טופס, צריך לחבר גם אותו.
13. לידים ממודעות באינסטגרם נכנסים גם הם? (הערה: ב-13.9 שני הלידים הגיעו מאינסטגרם, דרך אותו טופס של מטא - הם נשמרים בעמוד הפייסבוק, כמו לידים מפייסבוק.)

איפה לאה יכולה לראות לבד מה מחובר: הגדרות העסק במטא (business.facebook.com/settings) → אינטגרציות → גישה ללידים (Leads Access). (מהמחשב שלי אין הרשאה לראות את זה - בדיקה 13.9.)

בסוף השיחה לבקש: שישלחו למייל guralea@gmail.com הוראות חיבור כתובות ואת פרטי החיבור (מפתח API / כתובת Webhook) - כדי שאפשר יהיה לחבר את הטפסים באתרים.
