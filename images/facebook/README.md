# תמונות לטיזרים בפייסבוק

התיקיות כאן הן המאגר הקבוע שממנו ה-Skill `facebook-teaser` בוחר אוטומטית תמונה לכל פוסט יומי - בלי שצריך לבחור ידנית בכל פעם. שם כל תיקייה קבוע ולא ישתנה, כדי שה-Skill תמיד ידע איפה לחפש.

**איך זה עובד:** כל תמונה שתועלה לתיקייה הרלוונטית תיכנס אוטומטית לרוטציה. ה-Skill בודק ביומן (`.claude/skills/facebook-teaser/posted-log.md`) איזו תמונה שימשה לאחרונה בכל תיקייה, ובוחר אחת שלא שימשה לאחרונה - כך שאותה תמונה לא תחזור על עצמה שוב ושוב.

**פורמט:** כל קובץ תמונה רגיל (jpg/jpeg/png/webp) בתיקייה הנכונה - השם החופשי, אין צורך במוסכמת שם מיוחדת.

**אם תיקייה ריקה:** ה-Skill נופל אוטומטית לתמונה כללית (`images/hero-bike.jpg`), כך שאף פעם לא ייתקע בלי תמונה - אבל כמובן שתמונה ספציפית לנושא עדיפה.
